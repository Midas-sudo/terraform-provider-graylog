# graylog_lookup_data_adapter (Resource)

Manages a Graylog lookup data adapter.

## Example Usage

```terraform
resource "graylog_lookup_data_adapter" "example" {
  title       = "Terraform Lookup Adapter"
  name        = "terraform-lookup-adapter"
  description = "Managed by Terraform"

  config = {
    type                    = "csvfile"
    path                    = "/tmp/lookup-table.csv"
    separator               = ","
    quotechar               = "\""
    key_column              = "key"
    value_column            = "value"
    check_interval          = 60
    case_insensitive_lookup = false
    multi_value_lookup      = false
    cidr_lookup             = false
  }
}
```

## Configuration by type

`config` must include `type`. Graylog exposes adapter defaults via
[`graylog_lookup_adapter_types`](../data-sources/lookup_adapter_types.md)
(`default_config` and synthesized `requested_configuration`).

| Type | Common keys |
|---|---|
| `csvfile` | `path`, `separator`, `quotechar`, `key_column`, `value_column`, `check_interval`, `case_insensitive_lookup`, `multi_value_lookup`, `cidr_lookup` |
| `httpjsonpath` | `url`, `single_value_jsonpath`, `user_agent` |
| `dnslookup` | `lookup_type`, `server_ips`, `request_timeout` |
