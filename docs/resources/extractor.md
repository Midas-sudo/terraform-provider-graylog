# graylog_extractor (Resource)

Manages a Graylog extractor for a specific input.

## Example Usage

```terraform
data "graylog_inputs" "all" {}

resource "graylog_extractor" "example" {
  input_id         = data.graylog_inputs.all.inputs[0].id
  title            = "Terraform Extractor"
  source_field     = "message"
  target_field     = "message_copy"
  extractor_type   = "copy_input"
  cursor_strategy  = "copy"
  condition_type   = "none"
  condition_value  = ""
  extractor_config = {}
  converters       = []
  order            = 0
}
```

## Extractor and converter configuration

Graylog does not expose a rich discovery API for extractor configs. Use this matrix as a starting point.

| `extractor_type` | Typical `extractor_config` keys |
|---|---|
| `copy_input` | `{}` (empty object) |
| `regex` | `regex_value` |
| `regex_replace` | `regex`, `replacement`, optional `replace_all` |
| `split_and_index` | `split_by`, `index` |
| `substring` | `start_char`, `end_char` |
| `json` | JSON flattening / key options as accepted by Graylog |
| `grok` | `grok_pattern` |
| `lookup_table` | lookup table related keys |

| Converter `type` | Notes |
|---|---|
| `numeric` | Cast to number |
| `date` | Date parsing (`config` may include date format) |
| `hash` | Hashing |
| `lowercase` / `uppercase` | Case conversion |
| `tokenizer` | Tokenize value |
| `csv` | CSV parsing options in `config` |

`converters` is a list of objects like `{ type = "numeric", config = {} }`.

## Schema

### Required

- `condition_type` (String)
- `cursor_strategy` (String)
- `extractor_type` (String)
- `input_id` (String) Graylog input ID that owns this extractor.
- `source_field` (String)
- `target_field` (String)
- `title` (String)

### Optional

- `condition_value` (String)
- `converters` (Dynamic) List of converter objects. Each entry typically has `type` (e.g. `numeric`, `date`, `hash`, `lowercase`, `uppercase`, `tokenizer`) and optional `config` object.
- `extractor_config` (Dynamic) Extractor-specific configuration object. Keys depend on `extractor_type` (e.g. `regex` uses `regex_value`; `split_and_index` uses `split_by` / `index`; `copy_input` often uses `{}`). See the resource docs for a type matrix.
- `order` (Number)

### Read-Only

- `id` (String) The ID of this resource.
