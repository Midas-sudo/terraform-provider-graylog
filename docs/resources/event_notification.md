# graylog_event_notification (Resource)

Manages a Graylog event notification.

## Example Usage

```terraform
resource "graylog_event_notification" "example" {
  title       = "Terraform Event Notification"
  description = "Managed by Terraform"

  config = {
    type = "http-notification-v1"
    url  = "https://example.org/graylog/events"
  }
}
```

## Configuration by type

`config` must include `type`. Discover fields with
[`graylog_event_notification_types`](../data-sources/event_notification_types.md)
(built-in modern types plus legacy alarm callbacks from Graylog).

| Type | Common keys |
|---|---|
| `http-notification-v1` | `url` (required), `basic_auth`, `api_key`, `api_secret`, `api_key_as_header`, `skip_tls_verification` |
| `http-notification-v2` | `url`, `method`, `headers`, `body_template`, `content_type`, `skip_tls_verification` |
| `email-notification-v1` | `subject`, `sender`, `body_template`, `html_body_template`, `email_recipients`, `user_recipients` |
