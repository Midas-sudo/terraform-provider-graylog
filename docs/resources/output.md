# graylog_output (Resource)

Manages a Graylog output.

## Example Usage

```terraform
resource "graylog_output" "example" {
  title = "Terraform Output"
  type  = "LoggingOutput"
  configuration = {
    prefix = "terraform-output:"
  }
}
```

## Configuration by type

`configuration` keys depend on the output `type`. Discover fields with:

```terraform
data "graylog_output_types" "available" {}
```

| Type | Common keys |
|---|---|
| `LoggingOutput` | `prefix` (optional) |
| `GelfOutput` | `hostname`, `port`, `protocol`, and related GELF delivery keys |
