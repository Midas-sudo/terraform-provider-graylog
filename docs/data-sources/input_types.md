# graylog_input_types (Data Source)

Lists available Graylog input types and their `requested_configuration` fields. Use this to discover required/optional keys for `graylog_input.configuration`.

Each type includes `requested_configuration`: field name, Graylog field type, human name,
description, `is_optional`, JSON-encoded `default_value`, and optional `additional_info`.

## Example Usage

```terraform
data "graylog_input_types" "available" {}

output "syslog_udp_fields" {
  value = [
    for t in data.graylog_input_types.available.types : {
      type   = t.type
      fields = [for f in t.requested_configuration : "${f.name} (optional=${f.is_optional})"]
    }
    if t.type == "SyslogUDPInput"
  ]
}
```
